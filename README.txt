パチンコスペックラボ α23.5 iOS版 / Safariホーム画面Webアプリ

【重要】iOS標準「ファイル」アプリのHTMLプレビューでは、サンプルが空欄になったりタブ切替できないことがあります。必ずWebサイトに置いてSafariで開いてください。

【インストール手順】
1. ZIPを解凍して「index.html」「sw.js」「manifest.webmanifest」PNGアイコン3点を同じフォルダに置く。
2. HTTPS対応静的ホスティング（例: https://app.netlify.com/drop ）に解凍したフォルダごとアップロードする。
3. 発行されたHTTPS URLをiPhoneのSafariで開く。
4. Safariの共有メニュー→「ホーム画面に追加」でWebアプリとして開く。
5. ホーム画面のスペックラボから起動。初回オンライン起動後、キャッシュ成功でオフラインでも利用可能。

【機能】
PC版α23.5と同じ理論値9項目・LT期待出玉・リミット・賞球反映シミュレーション・ボーダー自動連動（小数第2位まで）・逆算・保存。
初期サンプルはエヴァ15（1/319.7）。
従来方式は実質250玉あたりのボーダーを自動反映。賞球反映方式は発射100玉あたりの必要スタートへ換算。
画面下部の6タブで切り替え、上部の保存メニューからJSONバックアップ・端末保存・復元が可能。

【注意】
・これはiOS Safari向けPWA（ホーム画面Webアプリ）であり、App Store向けのIPAではありません。
・公開先のURLはこのファイルだけでは発行されません。自分でHTTPSホスティングへ設置してください。
・端末内保存はサイトデータの消去で失われることがあるため、JSONバックアップも推奨。
・ブラウザのモバイル画面で機能検証していますが、iPhone実機での最終動作検証は未実施です。
